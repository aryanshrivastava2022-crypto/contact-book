# Contact Book
A simple Python Contact Book application that helps users manage their contacts.

# Features
- Add Contacts
- View All Contacts
- Search Contacts
- Delete Contacts
- User-Friendly Menu Interface

# Requirements
- Python 3.x

# How to Run
1. Download the project files.
2. Open the project folder.
3. Open a terminal or command prompt.
4. Run:
contact_book.py

# Sample Output
📒 Contact Book
1. Add Contact
2. View Contacts
3. Search Contact
4. Delete Contact
5. Exit
